# Journal guideline audit

Sources consulted (2026-09-10):
- Springer Nature / Genome Biology submission pages (Brief Report page retrieved via link.springer.com; Research-article formatting also corroborated via BMC-style Genome Biology guidance summaries citing Springer Nature author instructions). **Direct fetch of the full Research preparing-your-manuscript HTML timed out in this environment**; claims below that depend on secondary summaries are marked `VERIFY_BEFORE_SUBMIT`.
- Oxford Academic *Bioinformatics* Author guidelines (Original Papers section; accessible mirror of academic.oup.com content).

## Genome Biology — recommended article type
**Research** (primary) or **Method** (acceptable alternative framing as a reliability evaluation study).  
Not Brief Report (too long; >2 display items).  
Not Software (no new tool release as primary claim).

### Abstract
- Structured: **Background / Results / Conclusions**
- Target ≈ **250–350 words** (BMC Genome Biology commonly cites ~350; some mirrors say ≤250 — **VERIFY_BEFORE_SUBMIT** on the live Springer page before submission)
- No citations in abstract

### Organization (BMC Research style)
Background → Results → Discussion → Conclusions → Methods → Declarations (availability, competing interests, funding, authors’ contributions, acknowledgements) → References → Figure legends → Tables → Additional files

### Length / figures
- No strict Research word limit; typical **5,000–10,000** words excluding refs/additional files (`VERIFY_BEFORE_SUBMIT`)
- No strict figure cap; we use **6 main figures**, **2 main tables**

### References
- Numbered **Vancouver / BMC** style with square brackets in text

### Data / code
- Public accessions required; code must be available (GitHub/Zenodo recommended)

### Supplementary
- Additional files allowed; place secondary analyses there

## Bioinformatics (OUP) — backup article type
**Original Paper** (up to **7 typeset pages** ≈ **~5,000 words** excluding figures; manuscripts ≫20% over length may be returned administratively).

### Abstract
- Structured (≤ **150 words** recommended): **Motivation; Results; Availability and Implementation; Contact; Supplementary Information**

### Organization
Abstract → Introduction → System and Methods / Methods → Results / Discussion (often combined or sequential) → Acknowledgements → References → Figures/Tables as needed; heavy detail in Supplement

### References
- Author–year / OUP Bioinformatics style (adjust from Vancouver if submitting here)

### Data / code
- Strong availability requirement; software freely available to non-commercial users when software is central

## Positioning choice for this project
Prefer **Genome Biology Research** because the contribution is a multi-experiment reliability characterization with independent external validation, not a compact methods note. Use **Bioinformatics Original Paper** as a compressed backup with identical scientific claims.
